## Анализ работы библиотеки (SQL-проект)

## Что сделано
- Спроектирована база данных: 3 таблицы (читатели, книги, выдача), первичные и внешние ключи
- Заполнена тестовыми данными (10 читателей, 10 книг, 15 выдач)
- Рассчитаны штрафы за просрочку (14 дней бесплатно, далее 8.45 руб./день)

## Какие бизнес-задачи решены
1. **Топ популярных книг** (`JOIN` + `COUNT` + `GROUP BY`)
2. **Список должников с суммой штрафа** (`JOIN` + `SUM` + `WHERE fine_amount > 0`)
3. **Книги, которые ни разу не брали** (`LEFT JOIN` + `IS NULL`)
